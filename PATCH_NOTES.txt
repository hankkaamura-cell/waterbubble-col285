Water Bubble / Col 285 — Targeted Patch Notes
Prepared for Skye/Kanaan

Scope rule:
This patch only includes files tied directly to the confirmed fixes. It does not add METIS, EPIRB, or any unrelated module. It does not ship a rebuilt full project.

Files included:
1. src/main.ts
2. index.html
3. backend/app/spansh_client.py
4. package.json
5. package-lock.json

Fixes included:

PROBLEM: CRITICAL
Radius / center-system selection was being overridden by hardcoded coordinates.

Resolution:
- Removed hardcoded x/y/z from the Spansh request builder in src/main.ts.
- Requests now send reference=<selected system> and radius=<selected radius> only.
- This lets the proxy use the selected system as the actual Spansh radius center.

Outcome:
- APPLY should now query around the selected system rather than silently using the default hardcoded coordinate anchor.

------------------------------------------------------------

PROBLEM: CRITICAL
Backend/live-data startup path was not cleanly wired.

Resolution:
- Removed dependency on the external /frontend/waterbubble-client.js script from index.html.
- Added a direct frontend startup loader in src/main.ts.
- Startup now tries http://localhost:8000/api/systems first.
- If backend data is unavailable or returns zero systems, it falls back to /systems-search-Waterbubble.csv.
- Backend system rows are normalized into the SystemRecord shape used by the map.

Outcome:
- Frontend now has a clear data-source order: backend first, static CSV fallback second.
- Production preview no longer points at a missing /frontend/waterbubble-client.js script.

------------------------------------------------------------

PROBLEM: MODERATE
Trade-loop endpoint could look empty because sample data aged out of the 48-hour freshness window.

Resolution:
- Updated backend/app/spansh_client.py so sample market data imported with source="sample" is treated as fresh on backend startup.
- This preserves the 48-hour default freshness window for real/live market data.

Outcome:
- /api/trade-loops now returns the included demo/sample trade loops during local development instead of returning [] because the packaged sample timestamps got old.

------------------------------------------------------------

Resolution:

Outcome:
